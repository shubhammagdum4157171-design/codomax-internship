What happens when you log in

        
    
          
  1. Your browser checks it
    The form catches typos and weak passwords before anything leaves your device.
    2. 
          
  2. Fetch sends it
    Your details travel as JSON in a POST request to the Express API.
    3. 
          
  3. The server verifies it
    Passwords are hashed with scrypt, so the plain text is never saved.
    4. 
          
  4. You see the result
    The server's own message appears on screen, whether it succeeded or not.
